---
name: refactor
description: Refactorisation du code pour améliorer la lisibilité (SOLID, DRY).
---
Analyse le code fourni et propose une refactorisation approfondie pour améliorer sa qualité et sa maintenabilité, SANS modifier la logique métier ou le comportement final.

Concentre-toi sur :
1. Principes SOLID : Le code respecte-t-il la responsabilité unique ? Doit-on extraire des classes/fonctions ?
2. Principe DRY (Don't Repeat Yourself) : Identifie et mutualise le code dupliqué.
3. Complexité cyclomatique : Simplifie les conditions imbriquées (early returns, guard clauses).
4. Nommage : Propose des noms de variables/fonctions plus explicites si nécessaire.

Pour chaque proposition majeure, explique brièvement pourquoi elle améliore le code avant de fournir le code refactorisé.
